# 程序的安装与导出

> - 安装：将程序、库、头文件等产物，拷贝到系统的对应路径，如 bin、lib、include 目录下
> - 导出：对于库，安装仅仅是将其头文件、库文件拷贝至对应路径，若其它 CMake 项目要使用，则需要通过 `target_include_directories()`、`target_link_directories()` 这样的命令来使用，这种用法没有保留住 CMake Target 相关信息，不够简洁和自动化，所以需要额外的安装步骤来 *导出 CMake Target 信息*，这意味着生成一些特殊的 CMake 文件并放置到特定路径，以便其它 CMake 项目可以通过 `find_package()` 直接找到并使用库。

## 基础安装

`install()` 命令本质上是多个子命令，如 `install(TARGETS)`、`install(EXPORT)`、`install(FILES)`，这些命令效果不同。

`install(TARGETS)` 命令本质上是为一个 Target *注册* 安装要求，实际安装操作通过 `cmake --install build [--prefix <root>]` 执行。

安装时，CMake 会根据 Target 的产物类型决定安装位置：

|产物类型|位置变量|位置变量未定义时的默认位置|
|--|--|--|
|RUNTIME|${CMAKE_INSTALL_BINDIR}|bin|
|LIBRARY|${CMAKE_INSTALL_LIBDIR}|lib|
|ARCHIVE|${CMAKE_INSTALL_LIBDIR}|lib|
|PRIVATE_HEADER|${CMAKE_INSTALL_INCLUDEDIR}|include|
|PUBLIC_HEADER|${CMAKE_INSTALL_INCLUDEDIR}|include|
|FILE_SET (type HEADERS)|${CMAKE_INSTALL_INCLUDEDIR}|include|

默认情况下，`CMAKE_INSTALL_<dir>` 均未定义，若想要使用其*默认值*，则需要借助 `GNUInstallDirs` 模块：

```cmake
include(GNUInstallDirs)

install(
  TARGETS MyApp MyLib

  RUNTIME # 可指定某类型产物的安装路径
    DESTINATION ${CMAKE_INSTALL_BINDIR}/Subfolder

  FILE_SET HEADERS
)
```

## 导出目标信息

导出目标信息的核心逻辑：
1. 将需要导出的目标，加入到一个导出目标（*Export Target*）
2. 安装 Export Target（`install(EXPORT)`）

```cmake
# 将 MyProg 和 MyLib 加入到导出目标 MyProjectTargets
install(
    TARGETS
        MyProg MyLib
    EXPORT
        MyProjectTargets
)
include(GNUInstallDirs)
# 将导出目标安装到指定路径（find_package() 寻找的路径）下
# 这会生成一个 <ExportName>.cmake，本例中即 MyProjectTargets.cmake
install(
    EXPORT MyProjectTargets

    # ${CMAKE_INSTALL_LIBDIR}/cmake/ 是 find_package() 搜寻路径
    DESTINATIOn
        ${CMAKE_INSTALL_LIBDIR}/cmake/MyProject

    # 其它项目使用时，需要用 MyProject::MyProg、MyProject::MyLib 访问导出的 Target
    NAMESPACE MyProject::
)
```

根据 `find_package()` 的规则，当其寻找 *Package* 时，其会去预设路径寻找 *PackageConfig.cmake*（或其它指定格式名称），所以我们需要提供一个 *MyProjectConfig.cmake* 供查找，其内容很简单，包含导出目标文件即可：

```cmake
include(${CMAKE_CURRENT_LIST_DIR}/MyProjectTargets.cmake)
```

`CMAKE_CURRENT_LIST_DIR` 即当前文件所处路径，通过 `install(FILES)` 将 *MyProjectConfig.cmake* 安装到和 *MyProjectTargets.cmake* 同一位置，我们即可实现导出：

```cmake
install(
    FILES
        cmake/MyProjectConfig.cmake
    DESTINATION
        ${CMAKE_INSTALL_LIBDIR}/cmake/MyProject
)
```

## 声明版本号

`find_package(Package [VERSION] [EXACT])` 寻找 *Package* 时，会尝试寻找 *PackageConfigVersion.cmake* 获取版本号，然后与 VERSIOn 进行匹配，生成包版本号文件的核心命令是 `CMakePackageConfigHelpers` 模块提供的 `write_basic_package_version_file()`，该命令会将 `project(Name VERSION x.x.x)` 的版本号写入到指定文件中：

```cmake
project(MyProject VERSION 1.0.0)
include(CMakePackageConfigHelpers)
write_basic_package_version_file(
  ${CMAKE_CURRENT_BINARY_DIR}/MyProjectConfigVersion.cmake
  COMPATIBILITY ExactVersion
)
install(
  FILES
    cmake/MyProjectConfig.cmake
    ${CMAKE_CURRENT_BINARY_DIR}/MyProjectConfigVersion.cmake
  DESTINATION
    ${CMAKE_INSTALL_LIBDIR}/cmake/MyProject
)
```

`write_basic_package_version_file` 的 `COMPATIBILITY` 会参与 `find_package()` 的版本号匹配流程，支持的字段：

- ExactVersion
- AnyNewerVersion
- SameMajorVersion
- SameMinorVersion
