# 系统自省功能

> 系统自省，指的是检查当前系统环境、工具链是否支持一些功能/存在一些文件。CMake 有多个模块用于系统自省检查：

|||
|--|--|
|CheckIncludeFiles|检查 C/C++ 头文件是否存在|
|CheckCompilerFlag|检查编译器是否支持指定 Flag|
|CheckSourceCompiles|检查一段代码是否可编译|
|CheckIPOSupported|检查编译器是否支持 IPO|

## 检查头文件是否存在
```cmake
include(CheckIncludeFiles)
check_include_files(xxx.h
    HAS_XXX
)
if (HAS_XXX)
    target_compile_definitions(MyTarget PRIVATE HAS_XXX_MACRO)
endif()
```

## 检查一段代码是否可以编译
```cmake
include(CheckSourceCompiles)
check_source_compiles(CXX
  "
    int main() {
      int a, b, c;
      __builtin_add_overflow(a, b, &c);
    }
  "
  HAS_CHECKED_ADDITION
)
```

## 检查 IPO 支持
```cmake
include(CheckIPOSupported)
check_ipo_supported(RESULT result OUTPUT output)
if(result)
    set_property(TARGET foo PROPERTY INTERPROCEDURAL_OPTIMIZATION TRUE)
else()
    message(WARNING "IPO is not supported: ${output}")
endif()
```
