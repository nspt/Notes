# 自定义命令与文件生成

> 文件生成，指的是在普通的编译、链接之外的文件生成，比如 Qt 的元对象编译生成的 moc_xxx.h

## 文件生成的核心命令：`add_custom_command()`

`add_custom_command()` 可以为一个指定的文件设置自定义生成方式，并且使依赖该文件的目标和该文件依赖的目标，都能同步更新，例：

```cmake
add_executable(MyTool) # 假设 MyTool 被用于文件生成
add_custom_command(
    OUTPUT Generated.cxx # 文件生成的输出
    COMMAND MyTool -i input.txt -o Generated.cxx # 自定义生成命令
    DEPENDS MyTool input.txt # Genrated.cxx 依赖 Mytool 和 input.txt
    VERBATIM # 历史遗留问题，必须写，无意义
)
add_library(GeneratedObj OBJECT)
target_sources(GeneratedObj
    PRIVATE
        Generated.cxx # 此处使得库 GeneratedObj 依赖自定义生成文件 Generated.cxx
)
```

如果自定义文件生成的产物不是源文件，则无法如上例中 GeneratedObj 那样，通过 `target_sources()` 建立 CMake 目标与自定义生成文件的依赖关系，此时需要借助 `add_custom_target()` + `add_dependencies()` 命令，来实现依赖关系：

```cmake
add_custom_command(
    OUTPUT Generated.h
    # 省略
)
# 创建一个自定义目标 RunGenerator，令其依赖于 Generated.h
add_custom_target(RunGenerator
    DEPENDS Generated.h
)
add_library(MyLib INTERFACE)
target_sources(MyLib
    INTERFACE
        FILE_SET HEADERS
        BASE_DIRS ${CMAKE_CURRENT_BINARY_DIR}
        FILES
            ${CMAKE_CURRENT_BINARY_DIR}/Generated.h # MyLib 依赖自定义生成文件 Generated.h，但是此处无法自动生成依赖关系
)
# 令 MyLib 依赖自定义目标 RunGenerator，从而实现与 Generated.h 的依赖关系
add_dependencies(MyLib RunGenerator)
```
