# 0. 基本概念和使用方法

> CMake 生成构建系统的过程被叫做“配置”，CMake 本身被视为是构建系统的配置工具

## CMake Generator

CMake 支持的、不同的后端构建工具，如 Make、Ninja、Visual Studio，可以通过 `cmake --help` 查看支持的 Generator 及当前环境默认使用的 Generator，也可通过 `cmake -G <generator>` 来使用指定的 Generator。

## Generator 的单配置与多配置

这里的配置指的是构建类型（Build Configuration/Build Type）：

- Debug
- Release
- RelWithDebInfo
- MinSizeRel

多配置 Generator（如 Visual Studio），天生支持同一个构建系统，根据所给参数生成不同配置的结果，而单配置系统 Generator（如 Make、Ninja）非天生支持，尽管可以通过定义变量等形式实现，但是 CMake 做了区分。

对于单配置 Generator，CMake 在配置时就需要设置构建类型，通过 `CMAKE_BUILD_TYPE` 变量：

```
cmake -B build --DCMAKE_BUILD_TYPE=Debug
```

对于多配置 Generator，通过 CMake 进行构建时指定配置类型：

```
cmake --build build --config Debug
```

在使用多配置 Generator 时，CMake 的安装（`cmake install`）和 CTest 的使用也需要通过 `--config` 指定构建类型

## 基础常用命令

- `cmake -S <dir>`：指定CMakeLists.txt的位置
- `cmake -B <dir>`：指定构建系统的输出位置
- `cmake --build <dir>`：在指定位置（构建系统所处目录）执行构建
