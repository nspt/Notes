# 库的构建

`add_library(<name> [<type>])`，type 可以是：

- STATIC
- SHARED
- MODULE
- OBJECT
- INTERFACE

> 不建议在 `add_library()` 中指定库的类型，应该交由使用者通过 CMAKE 变量 `BUILD_SHARED_LIBS` （真或假）来决定，默认该变量未设置，此时构建静态库。

INTERFACE 类型的库即 Header-Only 库，基本操作：
```cmake
add_library(MyLib INTERFACE)
target_sources(MyLib
    INTERFACE
        FILE_SET HEADERS
        BASE_DIRS include
        FILES
            include/xxx.h
            include/yyy.h
)
```
