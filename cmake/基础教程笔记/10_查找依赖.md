# 查找依赖

最基础的查找依赖工具即 `find_package(Package)`，若 Package 成功找到，则 CMake 会自动将 *Package_FOUND* 变量设为真：

```cmake
find_package(MyLib)
# 若要求指定版本：find_package(MyLib VERSION x.x.x [EXACT])
# 若库是否存在都无所谓：find_package(MyLib QUIET)
if (MyLib_FOUND)
    # command
endif()
```

若 Package 成功找到，CMake 还会设置以下变量：

```cmake
Package_VERSION        # 实际找到的版本，如 4.5.3.1
Package_VERSION_MAJOR  # 实际找到的主版本号
Package_VERSION_MINOR  # 实际找到的次版本号
Package_VERSION_PATCH  # 实际找到的补丁版本号
Package_VERSION_TWEAK  # 实际找到的 tweak 版本号
Package_VERSION_COUNT  # 有几段数字
```

## 传递依赖

若使用库 A 需要依赖库 B、C，那么对于使用库 A 的项目，该如何简单通过 `find_package(A)` 即可自动依赖 B、C？方法就是在库 A 的 AConfig.cmake 中，通过 `find_dependency()` 将 B、C 的依赖传递给下游：

```cmake
include(ATargets.cmake)
include(CMakeFindDependencyMacro)
find_dependency(B)
find_dependency(C)
```

`find_dependency()` 本质上就是对 `find_package()` 的一个封装，只是将其放置在 PackageConfig.cmake 中，实现依赖传递的效果，`find_dependency()` 会继承 `find_package()` 的 `REQUIRED` 或 `QUIET`
