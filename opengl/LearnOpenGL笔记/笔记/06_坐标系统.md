# 06_坐标系统 Coordinate Systems

## 核心流程

OpenGL 中顶点坐标大致经历：

```text
Local Space
    ↓ model matrix
World Space
    ↓ view matrix
View Space
    ↓ projection matrix
Clip Space
    ↓ perspective division
NDC
    ↓ viewport transform
Screen Space
```

对应 shader 中常见写法：

```glsl
gl_Position = projection * view * model * vec4(aPos, 1.0);
```

注意矩阵从右往左作用：

```text
model → view → projection
```

---

## 各坐标空间含义

### Local Space

局部空间 / 物体空间。

模型原始顶点坐标所在的空间，描述的是模型自身形状。

例如一个立方体顶点范围是：

```text
[-0.5, 0.5]
```

这只是模型自己的尺寸和形状，不代表它在场景中的位置。

---

### World Space

世界空间。

通过 `model matrix` 把模型从局部空间放到世界中。

`model matrix` 负责：

```text
translate
rotate
scale
```

也就是决定物体在世界中的位置、朝向、大小。

---

### View Space

观察空间 / 摄像机空间。

通过 `view matrix` 把世界坐标转换到摄像机视角下。

OpenGL 本身没有真正的摄像机对象。

所谓摄像机移动，本质上通常是：

```text
反向移动整个场景
```

例如：

```cpp
view = glm::translate(view, glm::vec3(0.0f, 0.0f, -3.0f));
```

可以理解为场景整体远离摄像机，使物体看起来在前方。

OpenGL 常规理解：

```text
摄像机看向 -Z 方向
```

---

### Clip Space

裁剪空间。

`projection matrix` 把 view space 转换到 clip space。

Vertex Shader 输出的：

```glsl
gl_Position
```

是 clip space 坐标，不是 NDC，也不是屏幕坐标。

clip space 坐标是四维齐次坐标：

```text
(x, y, z, w)
```

OpenGL 用下面的范围进行裁剪：

```text
-w <= x <= w
-w <= y <= w
-w <= z <= w
```

一个顶点先通过透视投影矩阵变换到裁剪空间，然后 OpenGL 根据它的裁剪空间坐标是否满足 [-w, w] 来判断它是否在可见范围内。

投影矩阵把“点是否位于视锥体内”这个几何问题，转换成了“这个点的 clip space 坐标是否满足 -w <= x,y,z <= w”这个统一判断。

顶点先经过透视投影矩阵进入 clip space，然后用 [-w, w] 判断；[-w, w] 判断本质上是在提前判断它透视除法后会不会落入 NDC 的 [-1, 1]。

普通顶点在 view space 中通常是 (x, y, z, 1)；经过透视投影矩阵后，会变成 (x_clip, y_clip, z_clip, w_clip)，其中 w_clip 通常由原来的深度 z_view 决定，不同深度的顶点会得到不同的 w。



---

### NDC

标准化设备坐标。

裁剪之后，OpenGL 自动执行透视除法：

```text
x_ndc = x_clip / w_clip
y_ndc = y_clip / w_clip
z_ndc = z_clip / w_clip
```

得到 NDC。

NDC 范围：

```text
x: [-1, 1]
y: [-1, 1]
z: [-1, 1]
```

注意：

```text
gl_Position 不是 NDC
NDC 是 gl_Position 除以 w 之后的结果
```

---

### Screen Space

屏幕空间。

NDC 经过 `glViewport` 映射到窗口坐标。

例如：

```cpp
glViewport(0, 0, 800, 600);
```

大致表示：

```text
NDC x: [-1, 1] → screen x: [0, 800]
NDC y: [-1, 1] → screen y: [0, 600]
```

这个过程叫：

```text
viewport transform
```

---

## Model / View / Projection

### Model Matrix

局部空间 → 世界空间。

决定单个物体：

```text
在哪里
朝向如何
大小如何
```

同一个 VAO / VBO 可以用不同的 model matrix 绘制多个物体。

---

### View Matrix

世界空间 → 观察空间。

决定从哪个位置、哪个方向观察世界。

常见理解：

```text
移动摄像机 = 反向移动世界
```

---

### Projection Matrix

观察空间 → 裁剪空间。

决定相机的可见范围，以及是否有透视效果。

常见两种：

```text
orthographic projection
perspective projection
```

---

## 正交投影

```cpp
glm::ortho(left, right, bottom, top, near, far);
```

特点：

```text
没有近大远小
远近不影响物体大小
适合 2D、工程视图、正交视图
```

---

## 透视投影

```cpp
glm::perspective(fov, aspect, near, far);
```

参数：

```text
fov     视野角
aspect  宽高比
near    近平面
far     远平面
```

特点：

```text
近大远小
更接近真实视觉
可见范围是视锥体 frustum
```

透视效果的关键在于 `w`。

透视投影后，远处顶点通常会得到更大的 `w`，之后执行：

```text
x / w
y / w
z / w
```

远处顶点除完后更靠近中心，因此看起来更小。

---

## 深度测试

绘制 3D 物体时需要启用深度测试：

```cpp
glEnable(GL_DEPTH_TEST);
```

每帧清除颜色缓冲和深度缓冲：

```cpp
glClear(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT);
```

否则 OpenGL 默认主要按绘制顺序覆盖颜色，不能正确处理前后遮挡。

深度测试依赖 depth buffer / z-buffer：

```text
更近的 fragment 保留
更远的 fragment 丢弃
```

## 多个物体

多个相同模型不需要复制顶点数据。

常见做法：

```text
共用 VAO / VBO
每个物体使用不同 model matrix
每次绘制前更新 model uniform
```

示意：

```cpp
for (...) {
    glm::mat4 model = glm::mat4(1.0f);
    model = glm::translate(model, position);
    shader.setMat4("model", model);
    glDrawArrays(...);
}
```

## 易混点

### 1. `gl_Position` 是什么？

```text
gl_Position = clip space coordinate
```

不是：

```text
NDC
screen coordinate
pixel coordinate
```

---

### 2. NDC 什么时候得到？

```text
clip space → perspective division → NDC
```

透视除法由 OpenGL 自动完成。

---

### 3. 裁剪发生在哪里？

裁剪发生在 clip space。

判断范围不是：

```text
[-1, 1]
```

而是：

```text
[-w, w]
```

---

### 4. 为什么需要 w？

`w` 用于透视除法。

透视投影中的近大远小，核心就是最后除以 `w`。

---

### 5. 为什么矩阵写成 P * V * M？

因为 OpenGL / GLM 通常使用列向量约定。

```text
projection * view * model * vec4(position, 1.0)
```

实际执行顺序是：

```text
model → view → projection
```

---

### 6. 为什么物体放在 z = -3？

OpenGL 常规观察空间中，摄像机默认看向 `-Z` 方向。

所以物体在摄像机前方，通常是负 Z。

---

## 最终记忆版

```text
model       把模型放进世界
view        把世界变成摄像机视角
projection  把摄像机视角变成裁剪空间
```

完整流程：

```text
local → world → view → clip → NDC → screen
```

最关键的一句：

```glsl
gl_Position = projection * view * model * vec4(aPos, 1.0);
```

其中：

```text
gl_Position 是 clip space
NDC 是 gl_Position / w
screen space 是 NDC 经过 viewport transform
```
