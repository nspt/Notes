# 窗口与 Context 创建

窗口与 Context 是一一绑定的，通过 `glfwCreateWindow()` 创建窗口的同时即创建了一个对应的 Context：
```cpp
GLFWwindow* window = glfwCreateWindow(800, 600, "LearnOpenGL", NULL, NULL);
if (window == NULL)
{
    std::cout << "Failed to create GLFW window" << std::endl;
    glfwTerminate();
    return -1;
}
```

`glfwCreateWindow()` 创建窗口及 Context 所使用的参数，由 `glfwWindowHint()` 设置，`glfwWindowHint()` 设置的是全局参数，影响*下一次*调用 `glfwCreateWindow()` 的效果：
```cpp
glfwWindowHint(GLFW_CONTEXT_VERSION_MAJOR, 3);
glfwWindowHint(GLFW_CONTEXT_VERSION_MINOR, 3);
glfwWindowHint(GLFW_OPENGL_PROFILE, GLFW_OPENGL_CORE_PROFILE);
GLFWwindow* window = glfwCreateWindow(800, 600, "LearnOpenGL", NULL, NULL);
```

在使用 GLFW 时，总是要 `glfwInit()` 初始化，并在退出时通过 `glfwTerminate()` 清理资源。

**需要注意的是，GLFW 的很多函数虽然返回值是 int，但实际上返回的是 GLFW_TRUE/GLFW_FALSE（分别对应 1 和 0），应视为返回布尔值：**
```cpp
if (!glfwInit()) {// 当作返回 bool 处理
    return -1;
}
//...
while (!glfwWindowShouldClose(window)) {
    // render
}
```

因为 OpenGL 的函数都是操作*当前线程的 Context*，没有支持操作给定 Context 的方式，所以需要用 `glfwMakeContextCurrent()` 令一个指定窗口的 Context 作为当前 Context 后，才能调用 OpenGL 相关的函数，包括 GLAD 的函数名绑定：
```cpp
glfwMakeContextCurrent(window);
```

GLFW 的窗口尺寸变化可以通过 `glfwSetFramebufferSizeCallback()` 注册回调，回调函数的类型应为 `void(GLFWwindow* window, int width, int height)`，可以在窗口尺寸变化回调里，修改 OpenGL Viewport 尺寸：
```cpp
void framebuffer_size_callback(GLFWwindow* window, int width, int height)
{
    glViewport(0, 0, width, height);
}
glfwSetFramebufferSizeCallback(window, framebuffer_size_callback);
```

API：
- `int glfwInit(void)`
- `void glfwTerminate(void)`
- `void glfwWindowHint(int hint, int value)`
- `GLFWwindow* glfwCreateWindow(int width, int height, const char* title, GLFWmonitor* monitor, GLFWwindow* share)`
- `GLFWframebuffersizefun glfwSetFramebufferSizeCallback(GLFWwindow* window, GLFWframebuffersizefun callback)`
- `void glfwMakeContextCurrent(GLFWwindow* handle)`

# OpenGL 函数加载

询问/查询 OpenGL 函数地址的函数是由 GLFW 提供的 `glfwGetProcAddress()`，该函数根据函数名字符串，找到对应函数的地址并返回。而负责加载/注册/名称映射的，则是 GLAD 的 `gladLoadGLLoader()`，它借助 `glfwGetProcAddress()`，实现令 `glXXX` 名对应到实际的函数实现：
```cpp
if (!gladLoadGLLoader((GLADloadproc)glfwGetProcAddress))
{
    std::cout << "Failed to initialize GLAD" << std::endl;
    glfwTerminate();
    return -1;
}
```

基本的 OpenGL 信息打印：
```cpp
std::cout << "OpenGL Version: " << glGetString(GL_VERSION) << std::endl;
std::cout << "OpenGL Vendor: " << glGetString(GL_VENDOR) << std::endl;
std::cout << "OpenGL Renderer: " << glGetString(GL_RENDERER) << std::endl;
std::cout << "GLSL Version: " << glGetString(GL_SHADING_LANGUAGE_VERSION) << std::endl;
```

API：
- `GLFWglproc glfwGetProcAddress(const char* procname)`
- `int gladLoadGLLoader(GLADloadproc)`
- `const GLubyte* glGetString(GLenum name)`

# 渲染循环（*render loop*）与 I/O 处理

基础的渲染循环框架：
```cpp
while (!glfwWindowShouldClose(window))
{
    // render
    glfwSwapBuffers(window);
    glfwPollEvents();
}
```

`glfwWindowShouldClose()` 检查指定窗口的关闭标志是否为真，可以由用户通过 GUI 关闭使标志为真，也可以代码中通过 `glfwSetWindowShouldClose()` 设为真。

`glfwSwapBuffers()` 切换指定窗口的前后 Buffer，双缓冲（Double Buffering）可以理解为不直接在“正在显示的画面”上画，而是先在“后台画布”上画好，画完后一次性切换到屏幕上，它主要是为了避免用户看到绘制过程中的半成品画面。

`glfwPollEvents()` 处理尚未处理的事件，更新窗口状态，调用事件回调。由于 `glfwPollEvents()` 处理事件后会*更新状态*，所以除了事件回调，还可以通过主动查询的方式获取*记录的*按键状态：
```cpp
if (glfwGetKey(window, GLFW_KEY_ESCAPE) == GLFW_PRESS)
    glfwSetWindowShouldClose(window, true);
```

API：
- `int glfwWindowShouldClose(GLFWwindow* handle)`
- `void glfwSwapBuffers(GLFWwindow* handle)`
- `void glfwPollEvents(void)`

# 渲染

```cpp
glClearColor(0.2f, 0.3f, 0.3f, 1.0f);
glClear(GL_COLOR_BUFFER_BIT);
```

1. `void glClearColor(GLfloat red, GLfloat green, GLfloat blue, GLfloat alpha)`

    属于 *State-changing function*，设置清理画布（颜色缓冲区）时所用的颜色。

2. `void glClear(GLbitfield mask)`

    属于 *State-using Function*，清理画布（对于颜色缓冲区，使用 `glClearColor()` 指定的颜色）。`mask` 可以是按位或的 `GL_COLOR_BUFFER_BIT`, `GL_DEPTH_BUFFER_BIT` 和 `GL_STENCIL_BUFFER_BIT`。
